# Amaan Portfolio Website

My personal portfolio site, built and hosted with GitHub Pages.

**Live site:** https://amaanbkn.github.io/AmaanPortfolioWebsite.github.io/

## About

A static personal portfolio showcasing my background, skills, and projects in Data Science, Machine Learning, and Deep Learning. Built on top of the "Massively" HTML5 UP template and customized with my own content.

## Tech Stack

- HTML5, CSS3
- jQuery
- Scrollex (parallax/scroll effects)
- GitHub Pages (hosting)

## Running Locally

```bash

# open index.html in your browser, or serve it locally:
python -m http.server 8000
```
