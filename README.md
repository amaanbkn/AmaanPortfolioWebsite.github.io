# Amaan Portfolio Website

My personal portfolio website showcasing my background, skills, and projects in Data Science, Machine Learning, and Deep Learning.

**Live Website:** https://amaanbkn.github.io/AmaanPortfolioWebsite.github.io/

## About

A static personal portfolio website built using HTML, CSS, and JavaScript technologies. The website presents my technical skills, projects, background, and contact information in a clean and responsive interface.

The website is based on the **Massively** HTML5 UP template and has been customized with my own content and project information.

## Tech Stack

* HTML5
* CSS3
* jQuery
* Scrollex
* GitHub Pages

## Website Sections

* About / Introduction
* Skills
* Projects
* Contact

## Running Locally

```bash
git clone https://github.com/amaanbkn/AmaanPortfolioWebsite.github.io.git
cd AmaanPortfolioWebsite.github.io
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deployment

The website is hosted using **GitHub Pages**.
